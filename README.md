# HoursToPay website

The site is plain HTML files with no build step, so any free static host can serve the folder as it is.

- `index.html` is the calculator (homepage).
- `guides/` holds the guide pages, and `guides/index.html` lists them.
- `about.html`, `privacy.html` and `contact.html` are the pages AdSense expects.
- `site.css` styles every page except the calculator, which has its own styles inside it.
- `prices/` holds "what it costs in work hours" pages (iPhone 17, PS5, MacBook Air, Netflix, Spotify) for the Philippines, US, UK and Australia.
- `wages/` holds minimum wage pages for those four countries and salary-to-hourly pages (₱15,000 to ₱50,000 a month, $30,000 to $100,000 a year).
- `sitemap.xml` and `robots.txt` assume the site will live at hourstopay.com. Change the address in both if it doesn't.
- `content-plan.md` lists what to publish next. It is a note for you and does not need to be uploaded.

The calculator can be opened prefilled from a link, for example `index.html?price=69990&cur=PHP&item=iPhone+17&pay=755&per=day&hours=8`. Pay that comes from a link isn't saved over the visitor's own settings.

## Updating prices and wages

Every price and wage was checked on October 8, 2026, and each page lists its sources. The pages are generated by the scripts in `/mnt/project-files/hourstopay-tools/` (keep that folder off the live site). To update a price, change it in `more_pages.py` and run `python3 make_pages.py ../hourstopay` from that folder. Check prices at least when wages change: the Philippines in the second half of the year, the UK in April, Australia in July.

To add a guide by hand, copy an existing guide file, change the text, and add a link to it in `guides/index.html` and in the Guides list on `index.html`. If you later regenerate the pages, add the guide to the scripts too, or it won't appear in the generated guide list.

## What changed from the original hourstopay.html

- It's now a complete web page, with a page title, a description for search engines and link previews, and a site icon.
- A headline at the top explains what the tool does, so nobody mistakes it for a payroll calculator.
- **Take-home %** (optional) was added under My pay. If it's empty, results use gross pay. If you enter 80, results use 80% of gross pay. The result card shows which one is in use.
- The pay field now says what it is: "Pay per hour / day / month before tax".
- **Live exchange rates** come from open.er-api.com (free, no key) and are cached for 12 hours. If that service can't be reached, the built-in Oct 7, 2026 rates are used.
- Fixed: the currency-conversion row and the wishlist "Total" line used to show even when they should be hidden.
- Settings are saved under new storage names, so nothing carries over from the old artifact.

## Put it online for free (pick one)

**Netlify Drop** (easiest, no account setup needed to try)
1. Go to app.netlify.com/drop.
2. Drag the `hourstopay` folder onto the page.
3. You get a link like `something.netlify.app`. Sign in to keep it.

**Cloudflare Pages**
1. In the Cloudflare dashboard, open Workers & Pages, then Create, then Pages, then Upload assets.
2. Name the project `hourstopay` and upload the folder.
3. The site appears at `hourstopay.pages.dev`. Cloudflare is a good choice if you also buy the domain there.

**GitHub Pages**
1. Create a public repository and upload `index.html`.
2. In Settings, open Pages, choose "Deploy from a branch", then `main` and `/ (root)`.
3. The site appears at `yourname.github.io/reponame`.

When you buy hourstopay.com, each host has a "Custom domain" setting that walks you through connecting it.
